# Datasheets

Vendor manuals, datasheets and specifications for the CPUs and chips the
emulator models. These are third-party documents, kept under their published
names. Notes elsewhere in `docs/` and `clanker/` cite them by path.

- [MD00086 6.06 V2 MIPS32 Instruction Set.pdf](cpu/MD00086%206.06%20V2%20MIPS32%20Instruction%20Set.pdf): MIPS32 Architecture for Programmers, volume II: instruction set, revision 6.06.
- [MD00087 2.50 V2 MIPS64 Instruction Set.pdf](cpu/MD00087%202.50%20V2%20MIPS64%20Instruction%20Set.pdf): MIPS64 Architecture for Programmers, volume II: instruction set, revision 2.50.
- [MD00090 6.02 V3 MIPS32 Privileged Resource Architecture.pdf](cpu/MD00090%206.02%20V3%20MIPS32%20Privileged%20Resource%20Architecture.pdf): MIPS32 Architecture for Programmers, volume III: privileged resource architecture, revision 6.02.
- [R4000_um2.pdf](cpu/R4000_um2.pdf): MIPS R4000 Microprocessor User's Manual, second edition.
- [VR4300 MIPS RISC Microprocessor Users Manual 1995.pdf](cpu/VR4300%20MIPS%20RISC%20Microprocessor%20Users%20Manual%201995.pdf): VR4300 MIPS RISC microprocessor user's manual, 1995.
