# The cpu-tests that fail today, per CPU and engine. tests/cpu_tests.rs fails a run
# when a test fails that is not listed for its cell and when a listed test
# passes, so this file always says exactly what is broken. Every R4400 and
# R5000 test here passes on a real Indy (oracle/): each is an IRIS bug, not a
# test bug. The R10000 family has no oracle; its expectations are the manuals'
# (docs/r10000.md).
#
#   fpu/vec_*, fpu/cvt_*   FCSR Inexact/Invalid are not computed for ordinary
#                          arithmetic (clanker/jitv2/fpu-flags-are-computed-not-read.md)
#   fpu/trap_*, inexact    a trapped exception still writes its result and Flag
#                          bit (docs/findings.md, findings 3, 4 and 6)
#   mips4/*                an R4400 raises FPE for unimplemented COP1 encodings,
#                          IRIS raises RI (docs/findings.md)
#   mem/lwr_all_offsets, excep/cop2_unusable   docs/gotchas.md
#   cache/hit_inv_discards jitv2 implies tcache, whose write-through L1-D has no
#                          dirty line to discard
#                          (clanker/cpu/tcache-discards-dirty-data-semantics.md)
#   cache/hit_inv_discards, r10k/ch_bit   the R10000 family runs only the shadow
#                          cache, which records no lines: nothing to discard, and
#                          a secondary Hit never hits (docs/r10000.md)
#
# A fix that makes a test pass deletes its line in the same commit. A change
# that makes a test fail does not add one unless the gap is written up.
